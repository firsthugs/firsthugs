FREE PUBLISHING WITH GITHUB PAGES
1. Create a free GitHub account.
2. Create a new PUBLIC repository, for example: firsthugs.
3. Upload all 3 files from this folder.
4. Open the repository Settings.
5. Choose Pages.
6. Under Build and deployment, select "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.
8. GitHub will show your free website address after deployment.
